# История изменений

Формат по [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по [SemVer](https://semver.org/lang/ru/).

## [1.0.0] - 2026-09-21

### Исправлено

- Справка методов, конструкторов и свойств читается полностью: строка синтаксиса, параметры, тип и описание возвращаемого значения (#7). Ранее для большинства методов сигнатура выводилась без параметров.
- Тип свойства берется из строки `Тип:`, признак «Только чтение» - из раздела «Использование».
- Описание устаревших методов, свойств и типов не подменяется баннером «Не рекомендуется использовать»: баннер выводится перед описанием вместе с рекомендуемой заменой.

### Добавлено

- Параметры: маркер обязательности `(обязательный)` / `(необязательный)`, тип, описание, значение по умолчанию; вариадические параметры `<Имя1>,...,<ИмяN>`.
- Варианты синтаксиса метода (`Вариант синтаксиса: ...`) выводятся отдельными сигнатурами со своими параметрами и описанием.
- Поля `Signature.syntax` и `MethodDefinition.return_description`; JSON-источник принимает `syntax`, `return_description`, поле `required` необязательно.
- Автоматический keyword-поиск с пометкой в ответе, если semantic/hybrid недоступен.
- Переменные окружения `MCP_BSL_SEARCH_DEFAULT_MODE` и `MCP_BSL_CONFIG`; в Docker файл `/home/mcpuser/config.yml` передается серверу автоматически.
- Версия формата индекса эмбеддингов (`platform_context_meta`): индекс другой версии пересобирается при первом semantic/hybrid запросе.
- Поддержка разметки справки 8.3.10 (`div.V8SH_chapter`) наряду с 8.3.24+ (`p.V8SH_chapter`).

### Изменено

- Ответы инструментов на русском языке: заголовки разделов, маркеры параметров, сообщения об ошибках, `get_platform_info`.
- `ParameterDefinition.required` принимает `True` / `False` / `None` (не указано); маркер выводится только для `True` / `False`.
- В индекс эмбеддингов попадают полные описания методов и имена параметров.
- CPU-сервис `docker-compose.yml`: режим поиска по умолчанию `keyword`.
- Статус пакета `Production/Stable`.

## [0.1.0] - 2026-02-13 .. 2026-03-29

- Первая версия (без отдельного релиза): MCP-сервер с 9 инструментами (поиск keyword/semantic/hybrid, `info`, `get_member`, `get_members`, `get_constructors`, `get_platform_info`, документация по строгой типизации и стилю кода), чтение HBK-файлов платформы и JSON-выгрузок, мультиверсионность, YAML-конфигурация, транспорты STDIO / SSE / Streamable HTTP, Docker-образы CPU и GPU.
